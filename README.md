# 🌸 Tests Platform — Система онлайн-тестування

Цей проект — це сучасна платформа для створення та проходження тестів. Вона складається з потужного бекенду на **Laravel** та елегантного фронтенду на **Next.js**.

---

## 📋 Завдання проекту
Проект розроблено відповідно до навчальних вимог:
1. **Технології**: Laravel (API) + Next.js (SPA).
2. **Автентифікація**: Повна система реєстрації, логіну та підтвердження пошти.
3. **Ролі та авторизація**: Розподіл на `Admin` (створює тести, бачить статистику) та `Student` (проходить тести).
4. **Сутності**: 
   - `Tests` (Тести)
   - `Questions` (Питання) — зв'язок "один-до-багатьох" із тестами.
   - `Answers` (Відповіді) — зв'язок "один-до-багатьох" із питаннями.
   - `Attempts` (Спроби) — статистика проходжень.
5. **Локалізація**: Повна підтримка української та англійської мов.
6. **Дизайн**: Елегантний "Peach & Rose" стиль з високою читабельністю.

---

## 🛠 Що потрібно встановити (Prerequisites)

Перед початком переконайтеся, що у вас встановлено:
1. **PHP 8.2+** та менеджер пакетів **Composer**.
2. **Node.js 18+** та **NPM**.
3. **MySQL** (або OpenServer / XAMPP).
4. **Git** (щоб завантажити проект).

---

## 🚀 Як встановити проект (Step-by-Step)

### 1. Бекенд (Laravel API)
Відкрийте термінал у папці проекту:

1. Встановіть залежності:
   ```bash
   composer install
   ```
2. Налаштуйте файл оточення:
   - Скопіюйте `.env.example` у `.env`.
   - Створіть базу даних у MySQL (наприклад, з назвою `tests_platform`).
   - У файлі `.env` вкажіть дані до БД (`DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`).
3. Згенеруйте ключ додатку:
   ```bash
   php artisan key:generate
   ```
4. Запустіть міграції та початкові дані (тести та адміна):
   ```bash
   php artisan migrate --seed
   ```
5. Запустіть сервер:
   ```bash
   php artisan serve
   ```
   *Бекенд буде доступний за адресою: `http://localhost:8000`*

### 2. Фронтенд (Next.js)
Відкрийте **НОВИЙ** термінал і перейдіть у папку `frontend`:

1. Встановіть залежності:
   ```bash
   npm install
   ```
2. Запустіть проект:
   ```bash
   npm run dev
   ```
   *Фронтенд буде доступний за адресою: `http://localhost:3000`*

## 📡 API Reference (Для Postman)

Всі запити мають префікс `/api/v1`. Обов'язково додавайте заголовок `Accept: application/json`.

### Публічні (Auth)
- `POST /register` — Реєстрація.
- `POST /login` — Вхід (повертає токен).

### Приватні (Потрібен Bearer Token)
- `GET /me` — Профіль користувача.
- `GET /tests` — Список усіх тестів.
- `POST /tests` — Створення тесту (Admin).
- `GET /tests/{id}` — Деталі тесту з питаннями.
- `POST /tests/{id}/attempts` — Почати тест (Student).
- `POST /attempts/{id}/finish` — Завершити тест та отримати результат.
- `GET /attempts` — Історія спроб.
